## Upgrade notes

No action is required. Existing Jev keys and disabled-site settings carry over. Jev is now optional: standard pagination, supported carousels, and the Settings sample gallery work without an API key. TypeSafe usage charges may apply when an optional Jev connection is used.

## What changed

- Move through supported carousels with the arrow keys. List pagination takes priority unless you hover over a carousel or focus its slide controls.
- Use visible Load more controls and recognize more numbered and previous-page links locally.
- Keep page navigation aligned with updated search filters, preserve controls inside widgets, and respond while pages are still loading.
- Try the Settings gallery without connecting Jev, and find project and support links in its new footer.
