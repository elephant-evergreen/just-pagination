# Just Pagination v0.0.1

- Turn pages with ← and → on paginated lists where Chrome grants site access.
- Connect a TypeSafe Jev API key in **Just Pagination Settings**, then try the arrow keys or page numbers in the sample gallery.
- Use **Disable** or **Enable** in the toolbar to control the shortcut for the current site.

Requires desktop Chrome 120 or later and a [TypeSafe Jev API key](https://console.typesafe.ai/keys). TypeSafe usage charges may apply.
