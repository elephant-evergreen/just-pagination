## Upgrade notes

Existing keys and site settings carry over. Settings loads its sample photos from Pexels, so the gallery needs a network connection to display them. Each photo still links to its source.

## What changed

- Arrow shortcuts respond to real key presses and recheck the navigation target before turning a page.
- Numbered lists can work even when the current page is missing from the pager, as long as both adjacent links identify the same list.
- Loading gallery images from Pexels reduces the extension ZIP to about 94 KB.
